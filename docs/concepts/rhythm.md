# Concept: Rhythm / kinetic type (`rhythm`)

## Idea
Typography that moves to a beat. The index reads like a score: titles breathe, stretch and stack on a shared
tempo; scrolling is playing the piece. Swiss discipline underneath so it stays legible.

## Type (from canvas direction B)
- Display: a variable grotesque with a width and/or weight axis AND the `vietnamese` subset
  (candidates: Bricolage Grotesque, Inter Tight variable, Manrope variable; verify the subset).
- Body: Inter 17–18 px. Meta / numbers: IBM Plex Mono with tabular figures.

## Palette
- Light: white #FFFFFF, near-black #0E1116, muted #5A616B, electric blue #3B3BE8 (one accent).
- Dark: #0B0D10, #E6E8EB, accent #7C7CFF.

## Signature moments
- Home: post titles as a stacked score; on a global tempo (e.g. 96 bpm) weight/width pulse subtly; scroll scrubs
  the tempo; big tabular post numbers tick like a metronome.
- Hover / tap: a title stretches (variable width axis) and its neighbours make room.
- Transitions: titles slide into a 12-column grid position on the next page (shared-element view transition).
- Article: headings set on the beat as they enter; TOC and footnotes in the right margin; reading progress as a
  playhead.
