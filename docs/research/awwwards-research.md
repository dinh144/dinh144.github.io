# Awwwards research for the blog (2026-11-09)

Method: Firecrawl scrape of Awwwards lists + live sites (screenshots, branding/fonts extraction). Chrome extension was unusable (2 browsers connected, no way to ask user), so no DevTools computed-style checks. "SEEN" = in screenshot/extracted metadata. "INFERRED" = my guess.

## Key finding
Awwwards "blog / magazine / editorial / typography" lists are ~90% agency/portfolio/campaign sites. Real long-form reading sites with awards are rare. Most "blog" winners are WebGL/scroll-driven showpieces, which the user excluded. Only a handful are usable references.

## Awwwards judging
Source https://www.awwwards.com/about-evaluation/ : Design 40%, Usability 30%, Creativity 20%, Content 10%. >=18 jurors, 3 outliers dropped, 5-day vote. HM >= 6.5 jury score; SOTD = top scorers; Developer Award (on SOTD winners) needs dev-jury score > 7 (code quality, performance, accessibility per Dev Guidelines). SOTM = 8 best of month; SOTY.
Implication: content (writing) is only 10%; Creativity 20% rewards motion/WebGL a reading blog should skip. Design+Usability = 70%, which a calm, typographic blog can score on. Aim for the HM/typography-tag level (not SOTD) and treat Awwwards as inspiration, not a target.
