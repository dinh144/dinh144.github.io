Source: https://www.ui-skills.com/skills/registry.json (the registry the CLI and MCP serve), fetched 2026-11-09. Registry: 712 skills, 27 topics, 124 sources.

Ratings: core 9, useful 68, skip 635. SKILL.md bodies were read for every core skill and the useful ones that matter (see "Skills read"); the rest are rated from registry descriptions only.

Install form on every skill page: `npx skills add https://github.com/<user>/<repo> --skill <name>`. Project-scope flags of the `skills` CLI were NOT verified (nothing was installed); check `npx skills add --help` for the flag that targets `.claude/skills` (typically `-a claude-code`; default scope is the project, `-g` is global).

## Design.md section
https://www.ui-skills.com/design-md lists 18 curated DESIGN.md files from real products: Amplitude, Ant Design, Atlassian, Beta Gouv (DSFR), Clerk, Culture Amp, Executor, Firecrawl, HyperFrames, Juspay, Mintlify, Nuxt, Open Food Facts, Oxide Computer, QuiverAI, Unicef, Vercel, VoltAgent. Each page shows tokens (colors, type, spacing, components) with copy buttons and a last-updated date. Good as reference for token structure; closest to a developer-blog feel: Mintlify (docs, Geist Mono, near-white #fefdfb, green brand), Vercel (Geist, light and dark report pages), Nuxt (dark-first). The site's own https://www.ui-skills.com/design.md is an example: quiet, editorial, code-first; Inter Variable + JetBrains Mono; H1 text-4xl weight 450 tight tracking; sentence-case labels; container 7xl/3xl with px-5; page #fff, ink #151515, one accent #1F78FF. ui-skills.com is itself built with Astro. The `create-design-md` skill (ibelick) generates this file for a repo; impeccable and hallmark treat an existing DESIGN.md as a locked system.

## Playbook section
https://www.ui-skills.com/playbook ("Learn": interactive lessons distilled from the skills). 47 one-line tips, each with a live demo and related skills (6 tip pages fetched individually; the rest from the index summaries):
- **Prevent layout shifts with aspect-ratio**: aspect-ratio so content does not jump while an image loads
- **Balance headings**: text-balance for headings, text-pretty for body
- **Tabular nums**: tabular-nums for numbers in tables/data
- **44px touch targets**: at least 44x44px
- **Nested radius**: inner radius = outer radius - padding
- **Press feedback**: subtle :active scale near 0.96
- **Popovers from their trigger**
- **Spacing, not dividers**: group with space before adding rules
- **Preview next item in scroll lists**: show 16-32px of the next item
- **Neutral borders around images**: thin neutral outline, not a tinted ring
- **Truncate long titles**: line-clamp/truncate
- **Muted text contrast**
- **No scale-zero entrances**: start near 95%
- **Skeletons match content; skip spinners**
- **One accent per view**: secondary actions neutral
- **Body measure 60-75ch**
- **Shadows for depth, borders for structure**
- **Visible focus rings**: :focus-visible
- **Errors next to each field**
- **Visible labels on every field**: no placeholder-only labels
- **Empty states: one clear action**
- **Sentence case labels**: not all caps
- **Never color alone for status**
- **ease-out for entrances**: ease-in feels slow on open
- **Align icons by eye**
- **Icon stroke matches text**: 2px beside semibold, 1.5px beside regular
- **Outline icons default, fill active**
- **No glow on primary buttons**
- **Animate icon state changes**: cross-fade opacity+scale+blur
- **12px between nearby controls**
- **Full-width buttons inside page margins**
- **Heading line-height ~1.1**
- **Tighter tracking for large text**
- **Confirm destructive actions**
- **Fade edges of scrollable lists**: mask-image
- **Stagger hero animation ~100ms**: first load only
- **Short, subtle exits**: small translateY
- **Show nearby tooltips faster**
- **Interruptible CSS transitions**: CSS transitions for open/close
- **No repeated animation in routine UI**: tab switches instant
- **ease-out, not springs, for feedback**
- **Fade menus out on close**
- **Brand color for links/actions only**: headings neutral
- **Solid modal backdrops, not blur**: avoid expensive full-screen blur
- **Fade overflowing text instead of hard clip**
- **Matching enter and exit animations**
- **Soften label changes with a short blur**
